# 反作弊系统说明文档

## 系统概述

它的设计目的是告诉玩家游戏有这个规则自觉遵守,防止玩家利用Minecraft的各种机制漏洞（如传送bug、物品复制等）搞出莫名奇妙的bug，而不是完全阻止恶意作弊行为。

### 设计理念

- 🎭 **"虚掩一枪"** - 告诉玩家游戏有这个规则需要遵守,防止搞出一些奇奇妙妙的bug.
- 🔓 **易于绕过** - 只要修改数据包代码即可完全绕过所有限制
- 🎯 **目标用户** - 针对不熟悉数据包原理的普通玩家，一般玩家不会想到直接修改数据包

## 功能模块

### 1. 传送检测系统 (`ban_tp.mcfunction`)

**主要功能：** 检测并防止玩家瞬间移动（毕竟传送这种东西很容易出bug,尤其是多人游戏）

**工作原理：**

- 每tick记录玩家的三维坐标（x, y, z）
- 计算当前坐标与上一tick坐标的差值
- 如果任意轴向的位移超过 ±3 格，判定为非法传送
- 自动将玩家传送回上一个合法位置

**已知限制：**

- ⚠️ 玩家可以在半径3格以内进行传送而不被检测
- 末影珍珠可能触发误判

**提示信息：**
```
『多人游戏需要玩家间互相传送请使用系统手册.』
『请不要作弊呦』q(≧▽≦q)
这里可以引导玩家加你的相关群之类的,如果他来找你,有问题的话你可以给他管理员的 tag
```

---

### 2. 物品来源验证系统 (`anti_give.mcfunction`)

**主要功能：** 防止玩家通过非法手段获得物品

**工作原理：**
- 所有合法物品必须包含NBT标签 `{from_map:1b}`
- 每tick检查玩家的以下槽位：
  - 主手 (SelectedItem)
  - 副手 (Slot:-106b)
  - 头盔 (Slot:103b)
  - 胸甲 (Slot:102b)
  - 护腿 (Slot:101b)
  - 靴子 (Slot:100b)
- 未带有合法标签的物品会被替换为空气
- 掉落在地上物品会被转换为绿宝石(`在你的地图里可以把这个删掉,因为我的地图想做成《空洞骑士》那样,敌人只掉落一种掉落物,方便管理,不会出现掉一堆乱七八糟的东西塞满玩家的背包)

**管理员豁免：**

- 拥有 `Mana` 标签的玩家不受此限制

**重要提示：**
```mcfunction
# 给予的所有物品都必须这样写：
give @a emerald{from_map:1b} 1
# 否则会被系统判断为作弊清除！
```

---

### 3. 状态效果控制系统 (`anti_effect.mcfunction`)

**主要功能：** 限制玩家和怪物的状态效果，防止buff滥用

**玩家限制效果：**
- 力量 (Strength) - 完全禁止
- 火焰保护 (Fire Resistance) - 完全禁止
- 伤害吸收 (Absorption) - 需要特殊权限
- 生命提升 (Health Boost) - 完全禁止
- 漂浮 (Levitation) - 完全禁止
- 饱和 (Saturation) - 完全禁止
- 抗性提升 (Resistance) - 完全禁止
- 瞬间治疗 (Instant Health) - 需要特殊权限
- 生命恢复 (Regeneration) - 需要特殊权限

**特殊处理：**
- 跳跃提升会先清除再给予 I 级（防止高等级跳跃buff，同时保证地图给予的buff生效）

**权限控制：**
- 通过 `can_be_effect` 分数控制

如果你想通过指令给玩家特定 buff,记得必须把“can_be_effect”这个计分项设置成一定值.(比如设置为 200,就是10 秒内允许玩家拥有 buff).当然,这肯定是虚晃一枪对吧?这个期间,玩家肯定是在这个期间可以通过作弊来用指令给自己加buff的.所以说这个系统主要还是要让玩家知道有这个规`自觉遵守.

---

### 4. 游戏模式限制 (`anti_creative.mcfunction`)

**主要功能：** 防止玩家切换到创造模式

**工作原理：**
- 强制所有非管理员玩家进入冒险模式（Adventure Mode）
- 检测到非冒险模式时立即切换并发送警告

**管理员标识：**

- 拥有 `Mana` 标签的玩家可以使用创造模式
- 获取管理员权限：`/tag <玩家名> add Mana`

**提示信息：**

```
请不要作弊呦,管理员模式需要添加Mana这个tag,之后才可以开启创造模式
```

虽然是CTM地图,但这个地图我当时的设计是,在冒险模式下,会给你一把可以挖掘,刷怪笼的稿子,你如果想改成生存模式的话,直接改就可以了

## 管理员系统

### 管理员标签：`Mana`

拥有此标签的玩家可以：
- ✅ 切换创造模式
- ✅ 使用任何物品（无需 `from_map` 标签）
- ✅ 使用任何状态效果
- ✅ 自由传送（仍会触发检测但不影响）

### 添加管理员
```mcfunction
/tag <玩家名> add Mana
```

### 移除管理员
```mcfunction
/tag <玩家名> remove Mana
```
